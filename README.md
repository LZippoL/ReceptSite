# 🍲 Смаколик — Сучасна Книга Рецептів & Розумний Пошук

Сучасний кулінарний вебзастосунок з mobile-first дизайном, розумним пошуком страв за вмістом холодильника, інтерактивними чеклистами інгредієнтів, таймерами, режимом шеф-кухаря («Cooking Mode»), системою улюблених страв, списком покупок, відгуками та вбудованою CMS/панеллю автора.

---

## 🚀 Швидкий запуск проєкту

### Вимоги
- **Node.js** версії 18 або новішої
- **npm** (або pnpm / yarn)

### Кроки запуску
1. Встановіть залежності:
   ```bash
   npm install
   ```
2. Запустіть локальний сервер розробки:
   ```bash
   npm run dev
   ```
3. Відкрийте браузер за адресою: `http://localhost:5173`

4. Для перевірки production build:
   ```bash
   npm run build
   npm run preview
   ```

## 🌟 Головні можливості застосунку

1. **Mobile-First & App-Like UX**:
   - Нижня панель навігації для швидкого доступу великим пальцем на смартфонах.
   - Адаптивність від 360px до 4K моніторів.
   - Підтримка Світлої, Темної та Системної теми.
   - PWA (Progressive Web App): можливість встановити сайт як додаток на телефон із підтримкою офлайн-кешування.

2. **🧊 Розумний пошук з холодильника («Що приготувати?»)**:
   - Введення наявних продуктів у вигляді зручних тегів-чіпів із швидким автодоповненням.
   - Розділення результатів на 3 рівні:
     - *«Можна приготувати прямо зараз»* (є всі продукти)
     - *«Майже все є»* (не вистачає 1-2 інгредієнтів із чітким переліком)
     - *«Схожі рецепти»* (частковий збіг)
   - Розумний словник синонімів (яйце/яйця, помідор/томати, сир/пармезан/моцарела).
   - Фільтр базових продуктів (вода, сіль, перець, олія автоматично не блокують готування) з можливістю налаштування власних базових запасів.

3. **📖 Понад 40 повноцінних перевірених рецептів**:
   - Український червоний борщ, ніжні сирники, деруни, вареники з картоплею та вишнею, паста Карбонара та Болоньєзе, лазанья, піца Маргарита, шакшука, стейк Рібай, запечений лосось, чізкейк Сан-Себастьян, тірамісу, узвар, смузі тощо.
   - Жодного «Lorem Ipsum» — реальні грами, хвилини, калорії, Б/Ж/В та покрокові інструкції.

4. **🍳 Інтерактивна сторінка рецепта**:
   - **Калькулятор порцій** `[-] N [+]`: автоматично перераховує кількість кожного інгредієнта.
   - **Чеклист інгредієнтів**: відмічайте підготовлені продукти.
   - **Додати до списку покупок**: в один клік виберіть, які саме інгредієнти потрібно купити в супермаркеті.
   - **Інтерактивні таймери кроків**: із звуковим сигналом (Web Audio API) та святковим конфеті.
   - **Режим шеф-кухаря (Cooking Mode)**: повноекранний покроковий режим з великим шрифтом для зручного читання мокрими чи зайнятими руками на кухні.
   - **Шеринг**: підтримка Web Share API на смартфонах, копіювання посилання, Telegram, Viber, Facebook.

5. **🛒 Список покупок**:
   - Окрема сторінка `/shopping-list`: додавання власних товарів, викреслювання купленого, очищення та копіювання готового тексту для відправки в месенджери.

6. **❤️ Улюблені страви та персональні колекції**:
   - Збереження вподобаних рецептів в один дотик.
   - Створення власних колекцій («Сніданки», «На свята», «Спробувати», «Швидка вечеря»).

7. **⭐ Рейтинги та відгуки**:
   - Оцінка від 1 до 5 зірок, відгуки з фотографіями, сортування за корисністю та оцінкою.

8. **✍️ Вбудована CMS та візуальний редактор (Rich Text Editor)**:
   - Панель автора `/admin` для створення нових страв та статей без редагування коду.
   - Форматування тексту: H2-H4, жирний, курсив, списки, цитати, callout-поради шефа, таблиці, посилання та фотографії з підписами.

9. **🎯 SEO оптимізація**:
   - Семантичний HTML5, OpenGraph, Twitter Cards.
   - Schema.org `Recipe` та `Article` мікророзмітка JSON-LD для красивих сніпетів у Google.
   - `robots.txt` та `sitemap.xml`.

## 📁 Структура проєкту

```
src/
├── components/
│   ├── admin/       # Форми додавання рецептів та статей (AdminRecipeForm, AdminArticleForm)

│   ├── editor/      # Візуальний редактор контенту (RichTextEditor)
│   ├── fridge/      # Компоненти пошуку за холодильником (IngredientChipInput)
│   ├── layout/      # Шапка сайту, футер, нижнє мобільне меню
│   ├── recipe/      # Картка страви, калькулятор порцій, чеклист, таймер, режим шефа
│   ├── reviews/     # Відгуки, зірочки, модалка додавання відгуку
│   └── search/      # Глобальний пошук, фільтри (FilterSheet)
├── context/         # Стан теми (Theme), обраного (Favorites), списку покупок (ShoppingList), сповіщень (Toast)
├── data/
│   ├── articles/    # Початкові кулінарні статті
│   ├── categories.ts# 14 категорій, кухні світу та базові інгредієнти
│   ├── recipes/     # Початковий каталог 42 рецептів
│   └── reviews/     # Початкові відгуки
├── pages/           # Головна, Каталог, Сторінка рецепта, Холодильник, Статті, Профіль, Адмінка, 404
├── services/        # Service Layer: абстрагована робота з даними (recipeService, storageService)
├── types/           # TypeScript типи моделей
└── utils/           # Алгоритм підбору інгредієнтів, синоніми, SEO
```

## 📝 Як редагувати та додавати контент

### 1. Додавання рецепта через інтерфейс сайту (без коду)
1. Відкрийте сайт і перейдіть у розділ **«Панель автора (CMS)»** (кнопка шестірні ⚙️ у шапці або за адресою `/admin`).
2. Натисніть кнопку **«Новий рецепт»**.
3. Заповніть форму:
   - Назва та Slug (генерується автоматично латиницею).
   - Категорія та кухня.
   - Фото (вставте посилання на зображення).
   - Час приготування та порції.
   - Калорійність та Б/Ж/В.
   - Додайте інгредієнти з грамами/одиницями.
   - Додайте покрокові етапи з таймерами та підказками від шефа.
4. Натисніть **«Опублікувати рецепт»**. Він миттєво з'явиться в каталозі та у пошуку!

### 2. Додавання рецепта прямо у вихідні файли (для постійного коду)
Всі початкові рецепти зберігаються у файлі:
`src/data/recipes/initialRecipes.ts`
Просто додайте новий об'єкт рецепта у масив за існуючим зразком.

### 3. Як змінити категорії
Категорії налаштовуються у файлі:
`src/data/categories.ts`
Там можна змінити назву, emoji-іконку, опис та фонове зображення.

### 4. Як додати фотографію
- **Через посилання**: Використовуйте будь-яке пряме посилання на зображення (наприклад, з [Unsplash](https://unsplash.com) або власного хостингу).
- **Локально**: Помістіть файл у папку `public/images/назва.webp` і вкажіть шлях `/images/назва.webp`.

## 🚢 Деплой на GitHub Pages

Репозиторій налаштований для автоматичної публікації через **GitHub Actions**:
`.github/workflows/deploy.yml`

### Як опублікувати оновлення:
1. Зафіксуйте зміни у Git та надішліть їх у гілку `main`:
   ```bash
   git add .
   git commit -m "Оновлення рецептів та функцій"
   git push origin main
   ```
2. GitHub Actions автоматично запустить збірку `npm run build` і опублікує сайт на GitHub Pages.
3. У репозиторії перейдіть у **Settings → Pages** і переконайтеся, що **Source** встановлено на **GitHub Actions**.
4. Сайт буде доступний за адресою:
   `https://lzippol.github.io/ReceptSite/`

### Налаштування власного домену (Custom Domain)
1. У налаштуваннях репозиторію **Settings → Pages** у полі **Custom domain** введіть ваш домен (наприклад `smakolyk.ua`).
2. Додайте у вашого DNS-провайдера CNAME-запис, що вказує на `lzippol.github.io`.
3. У `vite.config.ts` змініть `base: '/'` замість `'/ReceptSite/'`.

## 🔌 Підключення Supabase / Реального бекенду в майбутньому

Проєкт спроєктовано за принципом чистої архітектури з виділеним **Service Layer** (`src/services/`):
- `recipeService.ts`
- `articleService.ts`
- `reviewService.ts`
- `storageService.ts`

Жоден React-компонент не прив'язаний жорстко до `localStorage`.

### Кроки для підключення Supabase:
1. Встановіть клієнт Supabase:
   ```bash
   npm install @supabase/supabase-js
   ```
2. Створіть таблиці в базі даних:
   - `recipes` (id, title, slug, ingredients JSONB, instructions JSONB, calories, etc.)
   - `reviews` (id, recipe_id, user_name, rating, comment, etc.)
   - `articles` (id, title, slug, content, etc.)
3. У файлі `src/services/recipeService.ts` замініть внутрішні методи `getAll()` на виклики `supabase.from('recipes').select('*')`.
4. Весь користувацький інтерфейс, роутинг та компоненти продовжать працювати без жодних змін!
